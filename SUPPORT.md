# Support

RTSPS Secure is a community, experimental project. Support is best-effort and
no response time is guaranteed.

## Before asking for help

1. Read [README.md](README.md), [docs/INSTALL.md](docs/INSTALL.md), and
   [docs/TESTING.md](docs/TESTING.md).
2. Confirm that you use 64-bit OBS Studio 33 on Windows x64.
3. Check the OBS log for `[RTSPS Secure]` messages.
4. Reproduce the issue in an isolated OBS profile if possible.

## Where to ask

- **Bug reports and feature requests:** use the GitHub issue templates.
- **Security issues:** follow [SECURITY.md](SECURITY.md); do not open a public
  issue with exploit details.
- **Installation questions:** include the exact installer or ZIP name and the
  checksum verification result.

## Information to include

- plugin version or commit;
- OBS version and operating system;
- steps to reproduce;
- expected and actual behavior;
- relevant logs with private data removed.

Do not post real camera certificates, private keys, passwords, tokens, public
IP addresses, complete scenes, or unredacted logs. Replace them with synthetic
values.

## Not supported

- OBS Studio 32 or older;
- OBS Flatpak;
- Windows ARM64;
- Linux and macOS runtime support (compile-only experiments);
- camera credentials, DNS hostnames, or RTSP over UDP;
- recovery of deleted OBS scenes or certificates.
